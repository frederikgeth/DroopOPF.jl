# M4 release evidence

`benchmarks/` contains the v0.4.0 reference measurements and PGLib provenance
generated by `examples/m4_benchmark_workflow.jl`. Each study runs in a fresh
Julia process, with one warm-up and three timed samples.

Elapsed time and allocations cover model construction, optimization and result
extraction. `process_peak_rss_bytes` is the OS process lifetime high-water mark
including Julia startup, compilation, warm-up and independent validation. It
includes native solver memory but cannot attribute that memory to one solve.
Measurements are machine-dependent, and the cases are too small to infer a
scaling law or select a scaling algorithm.
