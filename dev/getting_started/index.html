Installation and learning paths

Install Julia and the package

Use Julia 1.10 or newer. A Julia session shows a julia> prompt; the following is Julia code, entered there or saved in a .jl script:

import Pkg
Pkg.activate("droopopf-tutorial"; shared=true)
Pkg.add(url="https://github.com/frederikgeth/DroopOPF.jl.git", rev="v0.10.0-rc1")
using DroopOPF

The named environment keeps the tutorial's dependencies together. The revision pins the documented prerelease; use a specific revision for reproducible studies. Package installation requires network access. Ipopt and the other declared Julia dependencies are installed with the package; teaching examples require no additional input files.

If you already have a checkout, run this shell command from its root:

julia --project=. -e 'using Pkg; Pkg.instantiate()'

Then start julia --project=. for an interactive session in that environment. Pkg.instantiate() installs the dependencies described by the project/manifest; it does not run an optimization campaign.

Background or taskSuggested sequence

Familiar with AC OPF; new to autonomous controlsVolt/VAR → reactive modes → study workflows
Ready for controller designFirst OPF → droop optimization → droop security
Importing a saved operating pointUnits and signs → PSS/E → validation
Investigating an unsuccessful solveValidation → solvers → feasibility → robustness

The first OPF constructs every object explicitly; it contains no pre-existing case variable or hidden input file. Copy its blocks in order into one Julia session.

Check your installation

For a checkout, this shell command loads a bundled synthetic two-bus MATPOWER fixture, solves it and independently checks its equilibrium:

julia --project=. examples/release_smoke.jl

That smoke case uses the control assignments provided by its importer. The teaching case instead explicitly attaches a Volt/VAR curve so you can see its role.

Symbols, units and scope

Before transferring equipment data, read notation and units. Power fields use the case system base, branch phase angles use radians, and Volt/VAR slopes use voltage change per reactive-power change. A droop slope is not a reactive-power-per-voltage gain.
