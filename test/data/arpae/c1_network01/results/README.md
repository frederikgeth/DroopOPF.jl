# Challenge 1 Network Model 01 results

`scenario_01/` contains the source-faithful IEEE 14-bus AC OPF and AC SCOPF reproduction. `scenario_01_pmin0/` and `scenario_02_pmin0/` are historical Pmin-zero-only results. The current S1/S2 analysis variants, `scenario_01_pmin0_qsym/` and `scenario_02_pmin0_qsym/`, set Pmin to zero and symmetrize generator Q bounds. Both now contain OPF/SCOPF JSON, full state solutions, threshold tables, and margins. The original source cases and limits remain unchanged, and each study-case folder contains a CSV of original and modified generator bounds.

The updated Pmin-zero, symmetric-Q cases are reproducible with [`examples/s1_s2_arpae_pmin0_qsym.jl`](../../../../../examples/s1_s2_arpae_pmin0_qsym.jl). Their base-point tables come from [`examples/report_arpae_pmin0_qsym.py`](../../../../../examples/report_arpae_pmin0_qsym.py); state tables use [`examples/report_arpae14_scopf_states.py`](../../../../../examples/report_arpae14_scopf_states.py) and [`examples/report_arpae500_scopf_states.py`](../../../../../examples/report_arpae500_scopf_states.py). The source case and provenance are in [`../scenario_01/`](../scenario_01/). The S1/S2 reports are in [`artifacts/s1_arpae14/REPORT.md`](../../../../../artifacts/s1_arpae14/REPORT.md), [`artifacts/s2_scopf/ieee14/README.md`](../../../../../artifacts/s2_scopf/ieee14/README.md), and [`artifacts/s2_scopf/ieee500/README.md`](../../../../../artifacts/s2_scopf/ieee500/README.md).

Each result directory contains solver JSON, the parsed network model, a machine-readable summary, and full generator, voltage, branch, transformer, and shunt threshold tables. The fixed-point SCOPF checked declared contingencies and returned the base operating point without adding a contingency to its active master. A separate full master with both declared outages is also solved and retained as `scopf_ac_all_states.json`; its objective matches the fixed-point result. The contingency dispatch contains P/Q capability-limit excursions because the source formulation leaves those recourse variables unbounded. See each `scopf_scenario_summary.csv` and `scopf_generator_scenarios.csv` before interpreting `LOCALLY_SOLVED` as physical security.
